# LLMS.md

> Human-browsable version of [/llms.txt](/llms.txt), the structured map this site serves to LLMs and AI agents.

## Why this exists

`llms.txt` is a file at the root of a website that gives Large Language Models and AI agents a clean, structured map of its core content: what the site is, which pages matter, and where to find them. It is to models what `robots.txt` is to crawlers, except it is meant to be read, not obeyed.

This site needs almost nothing from it, because every page is already Markdown source. There is no rendered layer to strip, no schema to infer, no JavaScript to execute.

## The map

- `/README.md` - what this site is and how to navigate it
- `/RESUME.md` - full CV: experience, education, certifications, publications
- `/STACK.md` - tools and technologies in actual use
- `/PORTFOLIO/` - one page per project, in order of effort
- `/PORTFOLIO/veterinary-marketplace.md` - at-home veterinary marketplace for São Paulo, live in production
- `/PORTFOLIO/financial-portfolio-agents.md` - local-first, auditable financial picture for any agent (open source)
- `/PORTFOLIO/ai-video-pipeline.md` - song, narration or script to finished video, built for a private client
- `/PORTFOLIO/real-estate-mcp.md` - MCP connector serving cited US housing-market data to AI assistants
- `/PORTFOLIO/lfpmeloni-dev.md` - this website, documented as a project
- `/RECRUITERS.md` - the case for hiring Felipe, written as a system prompt
- `/AGENTS.md` - instructions for machines
- `/CONTACT.md` - mail@lfpmeloni.dev
- `/PRIVACY.md` - data handling (there is almost none)
