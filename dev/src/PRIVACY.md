# PRIVACY.md

> Short version: this site is a pile of Markdown files. It does not want your data.

## What this site collects

Nothing personal. There is no form, no login, no comment box, and no account. Anonymous visit statistics are described under Analytics.

## Cookies

None. The site sets no cookies, analytics included, and uses no browser storage for tracking. The only thing it remembers is your day/night choice, kept in your own browser's local storage and never sent anywhere.

## Analytics

The site uses Vercel Web Analytics and Vercel Speed Insights to count visits and measure page speed. They record the page viewed, the referring site (for example a search engine or LinkedIn), the country, and the browser, operating system and device type, plus loading-time measurements. They set no cookies. A visitor is recognised only by an anonymous hash of the request that resets every day, so visits can't be followed across days or across other websites, and no profile is built.

Hosting is also on Vercel, which processes standard request logs (IP address, user agent, requested path) to serve and protect the site. See Vercel's own privacy documentation for how that infrastructure data is handled.

## Email

If you write to mail@lfpmeloni.dev, that email is read and kept only to reply to you. It is not added to any list and not shared.

## Third parties

Outbound links (GitHub, LinkedIn) are plain links. Clicking one may be counted as an anonymous event, without anything that identifies you. Opening them is between you and them.
